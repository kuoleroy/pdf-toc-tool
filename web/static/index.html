PDF 书签工具（网页版）

1. 写入书签（txt → PDF）

先选txt：用[p页号]可留空，用印刷页码须填"正文第一页"两个输入框

2. 提取书签 / 电子书目录

3. 提取图片

内嵌默认orig；渲染默认jpeg；电子书内嵌仅orig
电子书内嵌按图片出现顺序

4. OCR 识别（扫描页文字）

PDF页号；仅PDF/EPUB/MOBI；首次识别自动下载模型（需联网，较慢）
识别目录必填，用于计算偏移量；识别文字可留空

5. PDF 解锁 / 加密

解锁生成 _已解锁.pdf；加密生成 _已加密_密码<密码>.pdf（AES-256，文件名自动带密码便于记忆）

导入外部AI识别的目录

粘贴AI识别出的目录文本，每行：标题+页码（支持印刷页码/页码范围/[p页号]），行首缩进表示层级；将格式化为标准格式并下载
